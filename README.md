## About this project
There used to be a site called [SpaceFinder by Fractured Atlas](https://media.fracturedatlas.org/spacefinder-ended). It was great for finding spaces for dance rehearsal, putting up a performance, a meeting, an event. It looked like what [this Seattle Space Finder website is like](https://www.spacefinderseattle.org/)...but [not quite as modern](https://web.archive.org/web/20150306174724/http://nyc.spacefinder.org/spaces.html).

I (Travis Amiel) have to book rehearsal space all the time for the shows I make. I used to go through one-by-one a list of sites I had in a folder of bookmarks. It was very time consuming.

The goal of this site is to be a slight improvement over that folder.

## How it was made
After making some different prototypes, I used [Bolt.new](https://bolt.new) to create a vanilla JavaScript site that would display and filter my list of spaces. I manually moved the code it created into web components since I think it looks nice. This seemed to be the best way to keep this simple and functional for...ever?

## What's next
I will continue to add/remove/modify space information as I learn it and add features I think would be useful.
